# 5C Audit Bot - Telegram бот для аудита 5С

**Версия:** 1.0.0  
**Методика:** МУ-52-2024 "5С в производстве"  
**Платформа:** Telegram Bot API  
**Назначение:** Оценка рабочих мест на овощном участке (резка овощей для блюд)

---

## 📱 Описание

**Telegram бот** для автоматизации аудита системы 5С на производственном участке. Позволяет проводить оценку рабочих мест, сохранять результаты и генерировать Excel отчеты прямо в Telegram.

### 🎯 Основные возможности:

- ✅ **Интерактивный аудит** 5 рабочих мест через Telegram
- ✅ **Оценка по 25 критериям** системы 5С (МУ-52-2024)
- ✅ **Фотофиксация** проблемных зон (загрузка фото через Telegram)
- ✅ **Генерация Excel отчетов** с:
  - Титульным листом
  - Чек-листом с результатами
  - Сводной таблицей
  - Детализацией по рабочим местам
  - Информацией о фотофиксации
  - **Шаблоном для ручного плана мероприятий**
  - Данными для создания графиков
- ✅ **Хранение истории** всех аудитов
- ✅ **Просмотр статистики** по всем аудитам
- ✅ **Управление фото** (просмотр, удаление)

## 🚀 Установка и запуск

### 1. Создайте бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите **токен бота**
4. Сохраните токен

### 2. Настройка проекта

```bash
# Клонируйте репозиторий (если не сделано)
cd /home/user/5cCheckList

# Установите зависимости
npm install

# Создайте файл .env
cp .env.example .env

# Отредактируйте .env и добавьте токен бота
nano .env
# или
code .env
```

В файле `.env` укажите:
```
BOT_TOKEN=ваш_токен_от_BotFather
```

### 3. Запуск бота

```bash
# Обычный запуск
npm start

# Запуск с автоматическим перезапуском (для разработки)
npm run dev

# Консольная версия (если нужно)
npm run console
```

## 📋 Как провести аудит

### Шаг 1: Начало аудита
1. Нажмите "📋 Новый аудит 5С"
2. Введите название участка (например: "Овощной участок")
3. Введите ваше ФИО
4. Укажите количество рабочих мест (по умолчанию: 5)

### Шаг 2: Оценка критериев
Бот последовательно предложит оценить каждый критерий для каждого рабочего места:

```
📌 1С: Сортировка
Освобождение от ненужных предметов

1C-1: На рабочем месте отсутствуют ненужные, неисправные предметы

Раб. место 1: 1 (выполнено) или 0 (не выполнено)?
```

**Ответьте:** `1` или `0`

Бот пройдет по всем:
- 5 этапам 5С
- 5 критериям в каждом этапе
- Всем указанным рабочим местам

### Шаг 3: Фотофиксация (опционально)
После оценки каждого критерия бот предложит добавить фото:

```
Добавить фотофиксацию для этого критерия?
```

**Ответьте:** `Да` или `Нет`

Если выберете "Да":
1. Укажите номер рабочего места
2. Введите описание (опционально)
3. Отправьте фото в чат

### Шаг 4: Завершение аудита
После оценки всех критериев бот:
1. Покажет итоговые результаты
2. Сгенерирует Excel отчет
3. Отправит отчет вам в чат

## 📊 Структура Excel отчета

Генерируемый отчет содержит **7 листов**:

### 1. Титульный лист
- Название отчета
- Дата проведения
- Аудитор
- Общий балл
- Уровень 5С

### 2. Чек-лист
- Все 25 критериев
- Оценки по каждому рабочему месту
- Итоги по секциям
- Общий итоговый балл

### 3. Сводка
- Таблица с баллами по секциям
- Проценты выполнения
- Уровни оценки

### 4. Детали по местам
- Таблица с баллами по каждому рабочему месту
- Средние значения

### 5. Фотофиксация
- Список всех фото
- Описания
- Имена файлов

### 6. План мероприятий
- **Шаблон для ручного заполнения**
- Заполняется пользователем после аудита

### 7. Данные для графиков
- Данные для создания гистограммы
- Данные для радарной диаграммы
- Инструкции по созданию графиков в Excel

---

## 📈 Как создать графики в Excel

Отчет содержит лист "Данные для графиков" с инструкциями:

### Гистограмма:
1. Откройте лист "Данные для графиков"
2. Выделите данные для гистограммы (столбцы A и B с секциями и процентами)
3. Вставка → График → Гистограмма
4. Настройте заголовок и оси

### Радарная диаграмма:
1. Выделите данные для радарной диаграммы
2. Вставка → График → Лепестковый
3. Настройте заголовок

## 📊 Система оценки

### 5 этапов 5С:

| Секция | Название | Критериев | Макс. балл |
|--------|----------|-----------|-------------|
| **1С** | Сортировка | 5 | 5 × N |
| **2С** | Соблюдение порядка | 5 | 5 × N |
| **3С** | Содержание в чистоте | 5 | 5 × N |
| **4С** | Стандартизация | 5 | 5 × N |
| **5С** | Совершенствование | 5 | 5 × N |
| | **ИТОГО** | **25** | **25 × N** |

> **N** - количество рабочих мест (по умолчанию 5)

### Уровни оценки:

| Баллы | Уровень | Цвет |
|-------|--------|------|
| ≥90% | Отлично | 🟢 |
| ≥72% | Хорошо | 🟣 |
| ≥56% | Удовлетворительно | 🟡 |
| ≥40% | Неудовлетворительно | 🟠 |
| <40% | Критично | 🔴 |

## ❓ FAQ - Часто задаваемые вопросы

### В: Как получить токен бота?
**О:** Обратитесь к [@BotFather](https://t.me/BotFather) в Telegram и создайте нового бота

### В: Где сохраняются данные?
**О:** Все данные (аудиты, фото, отчеты) сохраняются на сервере в папках `data/` и `reports/`

### В: Как просмотреть историю аудитов?
**О:** Нажмите "📊 Мои аудиты" в главном меню

### В: Можно ли удалить аудит?
**О:** Да, выберите аудит из списка и нажмите "Удалить аудит"

### В: Как добавить фото?
**О:** Во время аудита выберите "Добавить фотофиксацию" и отправьте фото в чат

### В: Почему общий балл 125 для 5 рабочих мест?
**О:** Это правильно! 25 критериев × 5 рабочих мест = 125 максимально. Каждый критерий оценивается для каждого рабочего места.

### В: Можно ли изменить количество рабочих мест?
**О:** Да, при создании нового аудита укажите нужное количество (1-10)

### В: Как изменить критерии оценки?
**О:** Отредактируйте файл `config/checklist.json`

## 📞 Поддержка и устранение неполадок

### Бот не запускается
1. Проверьте, что установлены все зависимости (`npm install`)
2. Убедитесь, что файл `.env` содержит правильный токен
3. Проверьте, что Node.js установлен и работает

### Бот не отвечает
1. Проверьте, что бот запущен (`npm start`)
2. Убедитесь, что токен бота правильный
3. Проверьте, что у бота нет ограничений от Telegram

### Ошибки при генерации отчета
1. Проверьте права на запись в папку `reports/`
2. Убедитесь, что достаточно места на диске
