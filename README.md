# 🥕 Бот аудита 5С на овощном участке (Telegram)

Telegram-бот, который проводит аудит рабочего места/участка по системе **5С**
и выдаёт отчёт в процентах по каждому шагу.

Чек-лист адаптирован из официальных методических указаний Федерального центра
компетенций в сфере производительности труда:

> **МУ-52-2024 «5С в производстве» (редакция № 3), Приложение № 8
> «Чек-лист аудита 5С»** — [производительность.рф](https://производительность.рф/documents/view/5075)

Пункты из производственного чек-листа переработаны под овощной участок
(инвентарь, семена, удобрения, грядки, теплицы, дорожки, хранение, безопасность).

## Что умеет бот

- Пошагово ведёт аудитора по **23 вопросам** в рамках 5 шагов 5С:
  1. 🗂️ Сортировка · 2. 📦 Соблюдение порядка · 3. 🧹 Чистота ·
     4. 📋 Стандартизация · 5. 🔄 Совершенствование.
- Каждый вопрос оценивается кнопками **«✅ Выполнено (1)»** / **«❌ Не выполнено (0)»**.
- Можно вернуться **назад** и пересмотреть ответ или **отменить** аудит.
- В конце формируется отчёт:
  - % и баллы по каждому шагу (с «палочками» ███░);
  - общий результат в % и его интерпретация;
  - список **невыполненных пунктов** (над чем работать).
- Название объекта аудита (например «Теплица №1») фиксируется в отчёте.

## Быстрый старт

### 1. Получить токен бота
Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен вида
`123456789:AA...`.

### 2. Подготовить окружение
```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Указать токен
```bash
cp .env.example .env             # затем впишите токен в файл .env
# либо без файла:
export BOT_TOKEN="123456789:AA..."
```

### 4. Запустить
```bash
python bot.py
```

Бот работает в режиме long polling (не нужен внешний сервер/домен) и отвечает
на команды: `/start`, `/help`, `/cancel`.

## Проверка без Telegram (тесты и пример)

```bash
pip install -r requirements.txt
python -m unittest discover -s tests -v   # тесты движка чек-листа
python example_report.py                   # пример готового отчёта
```

## Как поменять вопросы

Все критерии находятся в одном файле — **`checklist.py`**. Структура:

- `STEPS` — список из 5 шагов;
- у каждого шага ключ (`1C`…`5C`), имя, подзаголовок, пояснение и `criteria` —
  список вопросов (каждый = отдельный пункт оценки);
- в начале файла подписана переработка из МУ-52-2024.

Изменения автоматически подхватываются: подсчёт баллов, % и отчёта строится
по фактическому числу вопросов. При необходимости отредактируйте сразу и
печатную копию: **`ЧЕК_ЛИСТ_5С_овощной_участок.md`**.

## Структура проекта

```
bot.py                  # Telegram-бот (aiogram 3), FSM-диалог, кнопки
checklist.py            # шаги 5С и вопросы (адаптация МУ-52-2024) — правила
audit_engine.py         # логика аудита: ответы, навигация, расчёт, отчёт
example_report.py       # пример: прогон «эталонного» аудита
tests/test_engine.py    # unit-тесты логики
ЧЕК_ЛИСТ_5С_овощной_участок.md  # печатная версия чек-листа
requirements.txt        # aiogram, python-dotenv
.env.example            # шаблон токена
```
